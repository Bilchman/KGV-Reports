Лабораторна робота №4

Обробка та аналіз кольорових зображень: відображення, аналіз яскравості, гістограми та зміна кольорових характеристик.

Мета

Ознайомитись із методами обробки та аналізу кольорових зображень; отримати практичний досвід у побудові матриць яскравості та гістограм, а також виконанні змін кольорових характеристик, таких як бінаризація, перехід до відтінків сірого, створення негативу; створити програму для візуалізації та аналізу кольорових зображень.

Умова

  1. Виведення первинного кольорового зображення на екран.
  2. Виведення на екран матриці значень яскравості зображення.
  3. Побудова гістограми яскравості кольорового зображення.
  4. Зміна кольоровості:
    • бінаризація (перехід до чорно-білого);
    • перехід до відтінків сірого;
    • негатив;
    • побудова гістограми зображення в градаціях сірого.

Хід роботи

За основу роботи візьмемо та продовжимо працювати нам проєктом попередніх 3 робіт та розширимо програмний комплекс за допомогою бібліотек NumPy, Pillow та Tkinter.



  • Завдання 1: Виведення первинного кольорового зображення на екран

    Відображення вхідного файлу вже було реалізовано в попередніх роботах та здійснюється через завантаження засобами ImageIO.read_image із приведенням колірного простору до чотириканального RGBA. Для коректного відображення у вікні оригінальне зображення масштабується під розміри полотна за допомогою методу thumbnail() з інтерполяцією LANCZOS, розраховуються відступи для центрування кадру, а об'єкт PhotoImage розміщується на полотні.

  • Завдання 2: Виведення на екран матриці значень яскравості зображення

    Розрахунок яскравості реалізовано у методі ImageEditorLogic.lum_array. Оскільки людське око неоднаково сприймає яскравість різних хвиль, для кожного пікселя обчислюється фотометрична яскравість: Lum = 0.299*R + 0.587*G + 0.114*B. Векторизовані обчислення проводяться у форматі float32, після чого діапазон обмежується функцією np.clip(0, 255) та конвертується у 8-бітні цілі числа np.uint8. Візуалізація матриці здійснюється у вікні LumMatrixWindow де застосовано метод tk.Text. Програмно формуємо текстову матрицю де верхній рядок містить координати по осі X, кожен наступний рядок починається з індексу по осі Y, а комірки заповнюються цілочисельними значеннями яскравості від 0 до 255.

  • Завдання 3: Побудова гістограми яскравості кольорового зображення

    Побудову гістограми реалізовано методом ImageEditorLogic.histogram. Зображення аналізується за колірними каналами (R, G, B) за допомогою вбудованого методу img.histogram() та за яскравістю. Для оцінки яскравості викликається метод lum_array, де на основі формули описаної у завданні 2 обчислюється матриця інтенсивностей, після чого функція np.histogram(lum_array, bins=256, range=(0, 256)) підраховує кількість пікселів для кожної з градацій. На чорному полотні викреслюємо чотири лінії: червона, зелена, синя та біла(канал яскравості). Усі масиви нормалізуються відносно спільного глобального максимуму max_val, для коректного вертикального масштабування без виходу за межі вікна. Причому варто зазначити, що побудову гістограми в градаціях сірого (передбачену завданням 4) реалізовано в цьому ж модулі за тим самим математичним принципом. Це зумовлено тим, що перетворення кольорового зображення у напівтонове полягає саме у повному зведенні тривимірних координат RGB до єдиного скалярного значення яскравості кожного пікселя за тією ж формулою 0.299*R + 0.587*G + 0.114*B. Відповідно, розподіл яскравості кольорових пікселів і розподіл тонів безбарвного зображення є абсолютно однаковими числовими масивами, тому біла лінія описує обидва ці стани.

  • Завдання 4: Зміна кольоровості:

    1. Бінаризація: Перехід до чорно-білого формату виконується методом порогового відсікання. Отримуючи матрицю яскравості з lum_array, алгоритм застосовує векторизовану маску np.where(lum_array >= threshold, 255, 0), після чого пікселі, яскравість яких більша або дорівнює встановленому порогу threshold, набувають значення 255 (білий), а решта — 0 (чорний). Отриманий масив приводиться до типу uint8 і повертається як бінарне висококонтрастне зображення.
    2. Перехід до відтінків сірого: Перетворення повноколірного кадру на напівтоновий здійснюється шляхом прямої конвертації згенерованої 2D-матриці яскравості у графічний об'єкт за допомогою Image.fromarray(). Функція формує 8-бітне зображення, усуваючи колірну дисперсію та залишаючи лише чіткий рельєф.
    3. Негатив: Реалізовано ефект повної інверсії колірних тонів за формулою Inverted = 255 - Original. Завдяки зрізу масиву NumPy data[..., :3] математичне віднімання застосовується виключно до червоного, зеленого та синього каналів, а значення альфа-каналу залишаються інтактними, що гарантує збереження вихідної прозорості зображення.
    4. Побудова гістограми зображення в градаціях сірого: Як уже було розглянуто в пункті 3, частотний розподіл відтінків сірого повністю збігається з яскравістю вихідного зображення. При виборі фільтра Grayscale метод histogram() генерує ідентичний графік, де біла лінія виступає відображенням розподілу сірих тонів у діапазоні 0–255.

import tkinter as tk
from tkinter import filedialog, messagebox
from pathlib import Path
import numpy as np
from PIL import Image, ImageTk, ImageDraw, ImageFont

from data import EditSpec, BatchSpec

class ImageEditorLogic:
    @staticmethod
    def resize(image: Image.Image, width: int, height: int) -> Image.Image:
        width = max(1, int(width))
        height = max(1, int(height))
        return image.resize((width, height), Image.Resampling.LANCZOS)

    @staticmethod
    def resize_keep_aspect(image: Image.Image, width: int = None, height: int = None) -> Image.Image:
        if not width and not height:
            return image

        orig_width, orig_height = image.width, image.height
        if width and height:
            return ImageEditorLogic.resize(image, width, height)
        if width:
            height = max(1, int(width * (orig_height / orig_width)))
        else:
            width = max(1, int(height * (orig_width / orig_height)))
        return ImageEditorLogic.resize(image, width, height)

    @staticmethod
    def define_color_scheme(image: Image.Image) -> Image.Image:
        if image.mode in ("RGB", "RGBA"):
            return image
        return image.convert("RGBA")

    @staticmethod
    def balance(image: Image.Image, r_scale: float, g_scale: float, b_scale: float) -> Image.Image:
        img = ImageEditorLogic.define_color_scheme(image)
        data = np.array(img, dtype = np.float32)
        data[..., 0] *= r_scale
        data[..., 1] *= g_scale
        data[..., 2] *= b_scale
        data = np.clip(data, 0, 255).astype(np.uint8)
        return Image.fromarray(data)

    @staticmethod
    def recolor(image: Image.Image, old_rgb: tuple, new_rgb: tuple, tolerance: float = 20.0) -> Image.Image:
        img = ImageEditorLogic.define_color_scheme(image)
        data = np.array(img, dtype = np.int32)

        rgb = data[..., :3]
        target = np.array(old_rgb[:3], dtype = np.int32)
        distance = np.sum((rgb - target) ** 2, axis = -1)
        mask = distance <= (tolerance ** 2)

        data[..., :3][mask] = new_rgb[:3]
        return Image.fromarray(data.astype(np.uint8))

    @staticmethod
    def opacity(image: Image.Image, alpha: float) -> Image.Image:
        img = ImageEditorLogic.define_color_scheme(image)
        data = np.array(img, dtype=np.float32)

        data[..., 3] *= alpha

        data = np.clip(data, 0, 255).astype(np.uint8)
        return Image.fromarray(data)

    @staticmethod
    def contrast(image: Image.Image, factor: float) -> Image.Image:
        img = ImageEditorLogic.define_color_scheme(image)
        data = np.array(img, dtype=np.float32)

        avg_y = np.mean(data[..., :3], axis=(0, 1), keepdims=True)

        data[..., :3] = (data[..., :3] - avg_y) * factor + avg_y

        data = np.clip(data, 0, 255).astype(np.uint8)
        return Image.fromarray(data)

    @staticmethod
    def cut_area(image: Image.Image, box: tuple) -> Image.Image:
        img = ImageEditorLogic.define_color_scheme(image)
        data = np.array(img)
        x1, y1, x2, y2 = box

        data[y1:y2, x1:x2] = [0, 0, 0, 0]
        return Image.fromarray(data)

    @staticmethod
    def split_image(image: Image.Image, rows: int, cols: int) -> list:
        width, height = image.size
        tile_width, tile_height = width // cols, height // rows
        parts = []

        for row in range(rows):
            for col in range(cols):
                left = col * tile_width
                top = row * tile_height
                right = left + tile_width if col < cols - 1 else width
                bottom = top + tile_height if row < rows - 1 else height

                parts.append(image.crop((left, top, right, bottom)))
        return parts

    @staticmethod
    def combine(main_image: Image.Image, added_image: Image.Image, side: str) -> Image.Image:
        if side not in ("left", "right", "top", "bottom"):
            return main_image

        main_img = ImageEditorLogic.define_color_scheme(main_image)
        added_img = ImageEditorLogic.define_color_scheme(added_image)

        if side in ("left", "right"):
            temp_image = ImageEditorLogic.resize_keep_aspect(added_img, height=main_img.height)
            new_width = main_img.width + temp_image.width
            new_height = max(main_img.height, temp_image.height)
        else:
            temp_image = ImageEditorLogic.resize_keep_aspect(added_img, width=main_img.width)
            new_width = max(main_img.width, temp_image.width)
            new_height = main_img.height + temp_image.height

        new_canvas = Image.new("RGBA", (new_width, new_height), (0, 0, 0, 0))

        if side == "left":
            new_canvas.paste(temp_image, (0, 0))
            new_canvas.paste(main_img, (temp_image.width, 0))
        elif side == "right":
            new_canvas.paste(main_img, (0, 0))
            new_canvas.paste(temp_image, (main_img.width, 0))
        elif side == "top":
            new_canvas.paste(temp_image, (0, 0))
            new_canvas.paste(main_img, (0, temp_image.height))
        elif side == "bottom":
            new_canvas.paste(main_img, (0, 0))
            new_canvas.paste(temp_image, (0, main_img.height))

        return new_canvas

    @staticmethod
    def watermark(image: Image.Image, watermark: str, x: int, y: int, color: tuple, alpha: float, size: int) -> Image.Image:
        if size <= 0 or size >= 1028 or not watermark:
            return image.copy()

        img = ImageEditorLogic.define_color_scheme(image)

        overlay = Image.new("RGBA", img.size, (0, 0, 0, 0))
        draw = ImageDraw.Draw(overlay)

        alpha_val = int(max(0.0, min(1.0, alpha)) * 255)
        rgba_color = (int(color[0]), int(color[1]), int(color[2]), alpha_val)

        font = ImageFont.load_default(size=size)
        draw.text((x, y), watermark, fill=rgba_color, font=font)

        edited_img = Image.alpha_composite(img, overlay)

        return edited_img

    @staticmethod
    def lum_array(image: Image.Image) -> np.ndarray:
        img = ImageEditorLogic.define_color_scheme(image)
        data = np.array(img, dtype=np.float32)
        lum = data[..., 0] * 0.299 + data[..., 1] * 0.587 + data[..., 2] * 0.114

        return np.clip(lum, 0, 255).astype(np.uint8)

    @staticmethod
    def histogram(image: Image.Image, width: int = 512, height: int = 256) -> Image.Image:
        img = ImageEditorLogic.define_color_scheme(image)
        hist = img.histogram()
        r = hist[0:256]
        g = hist[256:512]
        b = hist[512:768]
        lum_array = ImageEditorLogic.lum_array(img)
        lum, _ = np.histogram(lum_array, bins=256, range=(0, 256))

        canvas = Image.new("RGB", (width, height), (0, 0, 0))
        draw = ImageDraw.Draw(canvas)

        max_val = max(max(r), max(g), max(b), max(lum))
        if max_val == 0:
            max_val = 1

        channels = [
            (r, (255, 50, 50)),
            (g, (50, 255, 50)),
            (b, (50, 120, 255)),
            (lum, (220, 220, 220))
        ]

        for data, color in channels:
            points = []
            for i in range(256):
                x = int(i * (width - 1) / 255)
                y = int((height - 1) - (data[i] / max_val) * (height - 1))
                points.append((x, y))

            draw.line(points, fill=color, width=2)

        draw.rectangle((0, 0, width - 1, height - 1), outline=(80, 80, 80), width=1)

        return canvas

    @staticmethod
    def binary(image: Image.Image, threshold: int = 128) -> Image.Image:
        img = ImageEditorLogic.define_color_scheme(image)
        lum_array = ImageEditorLogic.lum_array(img)

        lum = np.where(lum_array >= threshold, 255, 0).astype(np.uint8)

        return Image.fromarray(lum)


    @staticmethod
    def grayscale(image: Image.Image) -> Image.Image:
        img = ImageEditorLogic.define_color_scheme(image)
        gray = ImageEditorLogic.lum_array(img)
        return Image.fromarray(gray)

    @staticmethod
    def negative(image: Image.Image) -> Image.Image:
        img = ImageEditorLogic.define_color_scheme(image)
        data = np.array(img, dtype=np.uint8)

        data[..., :3] = 255 - data[..., :3]

        return Image.fromarray(data)

    @staticmethod
    def apply(image: Image.Image, spec: EditSpec) -> Image.Image:
        img = image.copy()

        if spec.combine_image:
            img = ImageEditorLogic.combine(img, spec.combine_image, spec.combine_side)
            spec.width = None
            spec.height = None

        if spec.width and spec.height:
            if (spec.width, spec.height) != (img.width, img.height):
                img = ImageEditorLogic.resize(img, spec.width, spec.height)
        elif spec.width or spec.height:
            img = ImageEditorLogic.resize_keep_aspect(img, spec.width, spec.height)

        if spec.tolerance > 0:
            img = ImageEditorLogic.recolor(img, spec.old_color, spec.new_color, spec.tolerance)

        if (spec.r, spec.g, spec.b) != (1.0, 1.0, 1.0):
            img = ImageEditorLogic.balance(img, spec.r, spec.g, spec.b)

        if spec.contrast != 1.0:
            img = ImageEditorLogic.contrast(img, spec.contrast)

        if spec.alpha != 1.0:
            img = ImageEditorLogic.opacity(img, spec.alpha)

        if spec.watermark_text:
            img = ImageEditorLogic.watermark(
                img,
                spec.watermark_text,
                spec.watermark_x,
                spec.watermark_y,
                spec.watermark_color,
                spec.watermark_alpha,
                spec.watermark_size
            )

        mode = getattr(spec, 'filter_mode', 'Default')
        if mode == "Binary":
            img = ImageEditorLogic.binary(img, getattr(spec, 'binary_threshold', 128))
        elif mode == "Grayscale":
            img = ImageEditorLogic.grayscale(img)
        elif mode == "Negative":
            img = ImageEditorLogic.negative(img)

        return img

class ImageIO:

    FORMAT_MAP = {
        ".png": "PNG",
        ".jpg": "JPEG",
        ".jpeg": "JPEG",
        ".webp": "WEBP",
        ".bmp": "BMP",
    }

    @staticmethod
    def read_image(path):
        with Image.open(path) as raw:
            return raw.convert("RGBA")

    @staticmethod
    def load_image(parent = None):
        path = filedialog.askopenfilename(parent = parent, filetypes = [("Images", "*.jpg *.jpeg *.png *.webp *.bmp *.tif *.tiff")])
        if not path:
            return None, None

        try:
            img = ImageIO.read_image(path)
            return img, path
        except Exception as e:
            messagebox.showerror("Error", f"Could not load image:\n{e}", parent = parent)
            return None, None

    @staticmethod
    def resolve_save_format(path: Path, chosen_type: str = "PNG"):
        ext = path.suffix.lower()
        if ext in ImageIO.FORMAT_MAP:
            return path, ImageIO.FORMAT_MAP[ext]

        format = ImageIO.FORMAT_MAP.get(f".{chosen_type.lower()}", "PNG")
        new_ext = next(i for i, j in ImageIO.FORMAT_MAP.items() if j == format)

        if not ext:
            return path.with_suffix(new_ext), format
        else:
            return path.with_name(path.name + new_ext), format

    @staticmethod
    def write_image(image, path, format):
        out = image
        if format in {"JPEG", "BMP"} and out.mode in {"RGBA", "LA", "P"}:
            out = out.convert("RGB")

        save_options = {}
        if format in {"JPEG", "WEBP"}:
            save_options["quality"] = 100

        out.save(path, format = format, **save_options)

    @staticmethod
    def save_image(image, parent = None):
        if not image:
            messagebox.showwarning("Warning", "No image to save.", parent = parent)
            return

        chosen_type = tk.StringVar(parent)

        file_path = filedialog.asksaveasfilename(parent = parent, title = "Save Image", defaultextension = "", typevariable = chosen_type,
            filetypes = [("PNG", "*.png"),
                         ("JPEG", "*.jpg"),
                         ("WEBP", "*.webp"),
                         ("BMP", "*.bmp")])

        if not file_path:
            return

        path, format = ImageIO.resolve_save_format(Path(file_path), chosen_type.get())

        try:
            ImageIO.write_image(image, path, format)
            messagebox.showinfo("Saved", f"Successfully saved as {format}!\n\nFile: {path}", parent = parent)
        except Exception as e:
            messagebox.showerror("Error", f"Could not save file:\n{e}", parent = parent)

class BatchProcessor:

    @staticmethod
    def resolve_output(path: Path, out_dir: Path, format_choice: str):
        if format_choice == "Keep Original":
            ext = path.suffix.lower()
            format = ImageIO.FORMAT_MAP.get(ext, "PNG")
        else:
            format = format_choice
            ext = f".{format_choice.lower()}"
            if ext == ".jpeg":
                ext = ".jpg"

        return out_dir / f"{path.stem}_batch{ext}", format

    @staticmethod
    def run(spec: BatchSpec, on_error = None):
        out_dir = Path(spec.output_dir)
        count = 0
        edit_spec = spec.edit_spec if spec.edit_spec is not None else EditSpec()

        for file_path in spec.input_paths:
            path = Path(file_path)
            try:
                img = ImageIO.read_image(path)
                img = ImageEditorLogic.apply(img, edit_spec)

                out_path, format = BatchProcessor.resolve_output(path, out_dir, spec.format_choice)
                ImageIO.write_image(img, out_path, format)
                count += 1
            except Exception as e:
                if on_error:
                    on_error(file_path, e)

        return count

class LumMatrixWindow(tk.Toplevel):
    def __init__(self, parent, image: Image.Image):
        super().__init__(parent)
        self.title("LumMatrix")
        self.geometry("750x520")
        self.transient(parent)

        self.matrix = ImageEditorLogic.lum_array(image)
        self.h, self.w = self.matrix.shape

        self.setup_ui()

    def setup_ui(self):
        top_frame = ttk.Frame(self, padding=8)
        top_frame.pack(fill="x")

        ttk.Label(top_frame, text=f"Image size: {self.w}x{self.h} px").pack(side="left", padx=(0, 4))

        text_frame = ttk.Frame(self)
        text_frame.pack(fill="both", expand=True, padx=8, pady=(0, 8))

        self.text_area = tk.Text(
            text_frame, wrap="none", font=("Consolas", 10),
            bg="#181818", fg="#00ff66", insertbackground="white"
        )

        vsb = ttk.Scrollbar(text_frame, orient="vertical", command=self.text_area.yview)
        hsb = ttk.Scrollbar(text_frame, orient="horizontal", command=self.text_area.xview)
        self.text_area.configure(yscrollcommand=vsb.set, xscrollcommand=hsb.set)

        self.text_area.grid(row=0, column=0, sticky="nsew")
        vsb.grid(row=0, column=1, sticky="ns")
        hsb.grid(row=1, column=0, sticky="ew")

        text_frame.grid_rowconfigure(0, weight=1)
        text_frame.grid_columnconfigure(0, weight=1)

        self.render_matrix()

    def render_matrix(self):
        start_x, start_y = 0, 0

        view_w = self.w
        view_h = self.h

        header_x = "Y \\ X |" + "".join(f"{(x + 1):>5}" for x in range(start_x, start_x + view_w))
        separator = "-" * len(header_x)

        lines = [header_x, separator]

        for y in range(start_y, start_y + view_h):
            row_vals = "".join(f"{int(self.matrix[y, x]):>5}" for x in range(start_x, start_x + view_w))
            lines.append(f"{(y + 1):>5} |{row_vals}")

        self.text_area.delete("1.0", "end")
        self.text_area.insert("1.0", "\n".join(lines))

class SlideshowWindow(tk.Toplevel):
    def __init__(self, parent):
        super().__init__(parent)
        self.title("Slideshow Player")
        self.geometry("800x600")
        self.transient(parent)

        self.image_paths = []
        self.current_index = 0
        self.is_playing = False
        self.next_id = None
        self.current_photo = None

        self.setup_ui()

    def setup_ui(self):
        top_frame = ttk.Frame(self, padding=5)
        top_frame.pack(side="top", fill="x")

        ttk.Button(top_frame, text="Open Images...", command=self.load_images).pack(side="left")
        self.lbl_status = ttk.Label(top_frame, text="No images selected")
        self.lbl_status.pack(side="left", padx=(10, 20))

        ttk.Label(top_frame, text="Delay (ms):", font=("", 9, "bold")).pack(side="left")

        self.speed_var = tk.StringVar(value="1000")
        self.speed_entry = ttk.Entry(top_frame, textvariable=self.speed_var, width=6)
        self.speed_entry.pack(side="left", padx=5)

        self.canvas = tk.Canvas(self, bg="black")
        self.canvas.pack(side="top", fill="both", expand=True)
        self.canvas.bind("<Configure>", lambda e: self.show_current_image())

    def update_speed_label(self):
        self.lbl_speed.config(text=f"{int(self.speed_var.get())} ms")

    def load_images(self):
        paths = filedialog.askopenfilenames(
            parent=self,
            title="Select Images for Slideshow",
            filetypes=[("Images", "*.jpg *.jpeg *.png *.webp *.bmp *.tif *.tiff")]
        )
        if paths:
            self.image_paths = list(paths)
            self.current_index = 0
            self.lbl_status.config(text=f"{len(self.image_paths)} images playing...")

            if not self.is_playing:
                self.is_playing = True
                self.play_next()

    def play_next(self):
        if not self.image_paths or not self.is_playing:
            return

        self.show_current_image()
        self.current_index = (self.current_index + 1) % len(self.image_paths)

        try:
            delay = int(self.speed_var.get())
            if delay < 1:
                delay = 1
        except ValueError:
            delay = 1000

        self.next_id = self.after(delay, self.play_next)

    def show_current_image(self):
        if not self.image_paths:
            return

        canvas_width = self.canvas.winfo_width()
        canvas_height = self.canvas.winfo_height()
        if canvas_width < 20 or canvas_height < 20:
            return

        try:
            img = ImageIO.read_image(self.image_paths[self.current_index])

            img.thumbnail((canvas_width, canvas_height), Image.Resampling.LANCZOS)
            self.current_photo = ImageTk.PhotoImage(img)

            self.canvas.delete("all")
            self.canvas.create_image(canvas_width // 2, canvas_height // 2, image=self.current_photo, anchor="center")
        except Exception as e:
            print(f"Skipping unreadable image: {e}")

    def on_close(self):
        self.is_playing = False
        if self.next_id:
            self.after_cancel(self.next_id)
        self.destroy()

        paths = filedialog.askopenfilenames(
            parent=self,
            title="Select Images for Batch",
            filetypes=[("Images", "*.jpg *.jpeg *.png *.webp *.bmp *.tif *.tiff")]
        )
        if paths:
            self.input_paths = list(paths)
            self.lbl_files.config(text=f"{len(self.input_paths)} image(s)")

    def select_folder(self):
        folder = filedialog.askdirectory(parent=self, title="Select Output Folder")
        if folder:
            self.output_dir = folder
            self.lbl_folder.config(text=Path(folder).name or folder)

    def run_batch(self):
        if not self.input_paths:
            messagebox.showwarning("Warning", "Please select input images first.", parent=self)
            return
        if not self.output_dir:
            messagebox.showwarning("Warning", "Please select an output folder first.", parent=self)
            return

        w_str = self.ent_w.get().strip()
        h_str = self.ent_h.get().strip()
        target_w = int(w_str) if w_str.isdigit() and int(w_str) > 0 else None
        target_h = int(h_str) if h_str.isdigit() and int(h_str) > 0 else None

        spec = BatchSpec(
            input_paths=self.input_paths,
            output_dir=self.output_dir,
            format_choice=self.format_var.get(),
            edit_spec=EditSpec(width=target_w, height=target_h),
        )

        count = BatchProcessor.run(spec, on_error=lambda file_path, e: print(f"Skipped {file_path}: {e}"))

        messagebox.showinfo("Batch Complete", f"Successfully processed {count} image(s).", parent=self.master)
        self.destroy()

            self.apply_edits()

    def reset_colors(self):
        self.overall_scale.set(1.0)
        self.r_scale.set(1.0)
        self.g_scale.set(1.0)
        self.b_scale.set(1.0)
        self.contrast_scale.set(1.0)
        self.alpha_scale.set(1.0)
        self.apply_edits()

    def reset_recolor(self):
        self.tolerance_scale.set(0)
        self.apply_edits()

    def on_dimension_change(self, changed_side):
        if self.is_updating or not self.original:
            return

        try:
            self.is_updating = True
            if changed_side == "w" and self.keep_aspect.get():
                val = self.width.get().strip()
                if val.isdigit() and int(val) > 0:
                    new_height = max(1, int(int(val) / self.aspect_ratio))
                    self.height.set(str(new_height))
            elif changed_side == "h" and self.keep_aspect.get():
                val = self.height.get().strip()
                if val.isdigit() and int(val) > 0:
                    new_width = max(1, int(int(val) * self.aspect_ratio))
                    self.width.set(str(new_width))
            self.is_updating = False
            self.apply_edits()
        except Exception:
            self.is_updating = False

    def apply_edits(self):
        if self.original is None:
            return

        overall = self.overall_scale.get()

        try:
            wm_x = int(self.wm_x_var.get())
        except ValueError:
            wm_x = 10
        try:
            wm_y = int(self.wm_y_var.get())
        except ValueError:
            wm_y = 10
        try:
            wm_size = int(self.wm_size_var.get())
        except ValueError:
            wm_size = 0

        spec = EditSpec(
            r=self.r_scale.get() * overall,
            g=self.g_scale.get() * overall,
            b=self.b_scale.get() * overall,
            contrast=self.contrast_scale.get(),
            alpha=self.alpha_scale.get(),
            filter_mode=self.filter_mode_var.get(),
            old_color=self.old_color,
            new_color=self.new_color,
            tolerance=self.tolerance_scale.get(),
            combine_image=getattr(self, 'combine_image', None),
            combine_side=self.combine_side_var.get(),
            watermark_text=self.watermark_text_var.get(),
            watermark_color=self.watermark_color,
            watermark_alpha=self.watermark_alpha_scale.get(),
            watermark_size=wm_size,
            watermark_x=wm_x,
            watermark_y=wm_y
        )

        try:
            width = int(self.width.get())
            height = int(self.height.get())
            if width > 0 and height > 0:
                spec.width = width
                spec.height = height
        except (ValueError, TypeError):
            pass

        self.edited = ImageEditorLogic.apply(self.original, spec)
        self.update_preview()
        self.update_histogram_view()

    def update_preview(self):
        if not self.edited:
            return

        canvas_width, canvas_height = self.canvas.winfo_width(), self.canvas.winfo_height()
        if canvas_width < 20 or canvas_height < 20: return

        current_tab = self.tabs.tab(self.tabs.select(), "text")

        rel_box = None
        if current_tab == "Crop" and hasattr(self, 'crop_x1') and self.preview:
            preview_width, preview_height = self.preview.width(), self.preview.height()
            rel_box = [
                (self.crop_x1 - self.img_x)/preview_width, (self.crop_y1 - self.img_y)/preview_height,
                (self.crop_x2 - self.img_x)/preview_width, (self.crop_y2 - self.img_y)/preview_height
            ]

        preview = self.edited.copy()
        old_width = preview.width
        preview.thumbnail((canvas_width - 16, canvas_height - 16), Image.Resampling.LANCZOS)

        self.preview_scale = preview.width / old_width
        self.img_x = (canvas_width - preview.width) // 2
        self.img_y = (canvas_height - preview.height) // 2

        self.preview = ImageTk.PhotoImage(preview)
        self.canvas.delete("image")
        self.canvas.create_image(self.img_x, self.img_y, image=self.preview, anchor="nw", tags="image")
        self.canvas.tag_lower("image")

        if current_tab == "Crop":
            if rel_box:
                preview_width, preview_height = self.preview.width(), self.preview.height()
                self.crop_x1, self.crop_y1 = self.img_x + rel_box[0]*preview_width, self.img_y + rel_box[1]*preview_height
                self.crop_x2, self.crop_y2 = self.img_x + rel_box[2]*preview_width, self.img_y + rel_box[3]*preview_height
                self.draw_crop_box()
            else:
                self.init_crop_box()
        elif current_tab == "Split":
            self.draw_split_grid()

    def on_tab_change(self, event):
        current_tab = self.tabs.tab(self.tabs.select(), "text")

        self.canvas.delete("crop_element")
        self.canvas.delete("split_grid")
        self.canvas.config(cursor="")

        if current_tab == "Crop":
            self.init_crop_box()
        elif current_tab == "Split":
            self.draw_split_grid()

    def action_split(self):
        if not self.original or self.is_updating:
            return
        try:
            rows, cols = int(self.split_rows.get()), int(self.split_cols.get())
            if rows < 1 or cols < 1: raise ValueError
        except ValueError:
            messagebox.showerror("Error", "Rows and Columns must be integers > 0.", parent=self.root)
            return

        folder = filedialog.askdirectory(parent=self.root, title="Select Folder to Save Split Parts")
        if not folder: return

        parts = ImageEditorLogic.split_image(self.edited, rows, cols)

        base_name = Path(self.file_path).stem if hasattr(self, 'file_path') and self.file_path else "image"

        for i, part in enumerate(parts):
            path = Path(folder) / f"{base_name}_part_{i+1}.png"
            ImageIO.write_image(part, path, "PNG")

        messagebox.showinfo("Success", f"Successfully saved {len(parts)} parts!", parent=self.root)

    def draw_split_grid(self):
        self.canvas.delete("split_grid")
        if self.tabs.tab(self.tabs.select(), "text") != "Split":
            return
        if not hasattr(self, 'preview') or not self.preview:
            return

        try:
            rows = int(self.split_rows_var.get())
            cols = int(self.split_cols_var.get())
            if rows < 1 or cols < 1: return
        except ValueError:
            return

        preview_width = self.preview.width()
        preview_height = self.preview.height()

        for col in range(1, cols):
            x = self.img_x + col * (preview_width / cols)
            self.canvas.create_line(x, self.img_y, x, self.img_y + preview_height, fill="red", dash=(4, 4), tags="split_grid", width=2)

        for row in range(1, rows):
            y = self.img_y + row * (preview_height / rows)
            self.canvas.create_line(self.img_x, y, self.img_x + preview_width, y, fill="red", dash=(4, 4), tags="split_grid", width=2)

    def get_selected_box(self):
        x1 = int(((self.crop_x1 - self.img_x) / self.preview_scale) * (self.original.width / self.edited.width))
        y1 = int(((self.crop_y1 - self.img_y) / self.preview_scale) * (self.original.height / self.edited.height))
        x2 = int(((self.crop_x2 - self.img_x) / self.preview_scale) * (self.original.width / self.edited.width))
        y2 = int(((self.crop_y2 - self.img_y) / self.preview_scale) * (self.original.height / self.edited.height))

        return (max(0, x1), max(0, y1), min(self.original.width, x2), min(self.original.height, y2))

    def action_crop(self):

        box = self.get_selected_box()
        self.original = self.original.crop(box)

        self.height.set(str(self.original.height))
        self.is_updating = False

        self.apply_edits()

    def init_crop_box(self):
        if not hasattr(self, 'preview') or not self.preview:
            return
        preview_width, preview_height = self.preview.width(), self.preview.height()

        center_x, center_y = self.img_x + preview_width/2, self.img_y + preview_height/2
        box_w, box_h = preview_width * 0.8, preview_height * 0.8

        self.crop_x1 = center_x - box_w/2
        self.crop_y1 = center_y - box_h/2
        self.crop_x2 = center_x + box_w/2
        self.crop_y2 = center_y + box_h/2

        self.draw_crop_box()

    def draw_crop_box(self):
        self.canvas.delete("crop_element")
        if not hasattr(self, 'crop_x1'):
            return

        self.canvas.create_rectangle(
            self.crop_x1, self.crop_y1, self.crop_x2, self.crop_y2,
            outline="#00aaff", width=2, dash=(5, 5), tags="crop_element"
        )

        h = 4
        points = {
            "nw": (self.crop_x1, self.crop_y1), "ne": (self.crop_x2, self.crop_y1),
            "sw": (self.crop_x1, self.crop_y2), "se": (self.crop_x2, self.crop_y2),
            "n": ((self.crop_x1+self.crop_x2)/2, self.crop_y1),
            "s": ((self.crop_x1+self.crop_x2)/2, self.crop_y2),
            "w": (self.crop_x1, (self.crop_y1+self.crop_y2)/2),
            "e": (self.crop_x2, (self.crop_y1+self.crop_y2)/2)
        }

        for name, (x, y) in points.items():
            self.canvas.create_rectangle(
                x-h, y-h, x+h, y+h, fill="white", outline="#00aaff",
                tags=("crop_element", f"handle_{name}")
            )

    def on_mouse_down(self, event):
        self.drag_mode = None
        if self.tabs.tab(self.tabs.select(), "text") != "Crop":
            return

        items = self.canvas.find_withtag("current")
        self.last_x, self.last_y = event.x, event.y

        if items:
            tags = self.canvas.gettags(items[0])
            for tag in tags:
                if tag.startswith("handle_"):
                    self.drag_mode = tag.split("_")[1]
                    return

        if self.crop_x1 < event.x < self.crop_x2 and self.crop_y1 < event.y < self.crop_y2:
            self.drag_mode = "move"

    def on_mouse_drag(self, event):
        if self.tabs.tab(self.tabs.select(), "text") != "Crop":
            return
        if not self.drag_mode:
            return

        dx = event.x - self.last_x
        dy = event.y - self.last_y
        self.last_x, self.last_y = event.x, event.y

        max_x = self.img_x + self.preview.width()
        max_y = self.img_y + self.preview.height()
        min_w, min_h = 30, 30

        if self.drag_mode == "move":
            if self.crop_x1 + dx < self.img_x:
                dx = self.img_x - self.crop_x1
            if self.crop_x2 + dx > max_x:
                dx = max_x - self.crop_x2
            if self.crop_y1 + dy < self.img_y:
                dy = self.img_y - self.crop_y1
            if self.crop_y2 + dy > max_y:
                dy = max_y - self.crop_y2

            self.crop_x1 += dx; self.crop_x2 += dx
            self.crop_y1 += dy; self.crop_y2 += dy
        else:
            if "n" in self.drag_mode:
                self.crop_y1 = min(self.crop_y2 - min_h, max(self.img_y, self.crop_y1 + dy))
            if "s" in self.drag_mode:
                self.crop_y2 = max(self.crop_y1 + min_h, min(max_y, self.crop_y2 + dy))
            if "w" in self.drag_mode:
                self.crop_x1 = min(self.crop_x2 - min_w, max(self.img_x, self.crop_x1 + dx))
            if "e" in self.drag_mode:
                self.crop_x2 = max(self.crop_x1 + min_w, min(max_x, self.crop_x2 + dx))

        self.draw_crop_box()

    def on_mouse_hover(self, event):
        if self.tabs.tab(self.tabs.select(), "text") != "Crop":
            self.canvas.config(cursor="")
            return

        items = self.canvas.find_withtag("current")
        cursor = ""
        if items:
            tags = self.canvas.gettags(items[0])
            for tag in tags:
                if tag.startswith("handle_"):
                    cursor = "crosshair"
                    break
            else:
                if self.crop_x1 < event.x < self.crop_x2 and self.crop_y1 < event.y < self.crop_y2:
                    cursor = "fleur"
        self.canvas.config(cursor=cursor)

Висновки

Під час виконання лабораторної роботи ми навчилися працювати з яскравістю, кольорами та гістограмами зображень за допомогою Python, Pillow та NumPy, а також розширили наш інтерфейс у Tkinter. Було створено функцію розрахунку яскравості кожного пікселя за стандартною формулою, додано фільтри відтінків сірого, бінаризації, негатива, а також побудовано графік гістограми. Під час роботи ми зіткнулися з кількома практичними проблемами та успішно їх вирішили. По-перше, спроба вивести матрицю значень яскравості через стандартну таблицю Treeview намертво вішала програму на реальних фотографіях, бо створювалися тисячі важких елементів. Ми спростили це і зробили вивід через звичайне текстове поле. По-друге, ми розібралися, чому при зміні кольорів гістограма стає посіченою (з'являються голки вгору та провали на нуль). З'ясувалося, що це не баг у програмі, а нормальний наслідок округлення, бо коли ми множимо пікселі на числа, частина значень перескакує і виникає порожнє місце, а частина злипається в одну комірку і виникає голка і така поведінка є абсолютно нормальною, проте в сучасних графічних редакторах такого ефекту не видно через значно більшу роздільну здатність каналів, на відміну від 8 біт розглянутих у цій лабораторній роботі. Крім того, у функції негатива ми інвертували лише кольори RGB і не чіпали четвертий канал, щоб не зламати прозорість зображення. А при побудові графіків з'ясували, що гістограма яскравості та гістограма чорно-білого фото це абсолютно одне й те саме, тому їх логічно об'єднати на одному екрані. Ця робота допомогла зрозуміти, як фотографії влаштовані зсередини на рівні чисел і матриць, та як оптимізувати інтерфейс, щоб він не зависав, а отримані навички неодмінно стануть у нагоді при розробці майбутніх графічних проєктів.
