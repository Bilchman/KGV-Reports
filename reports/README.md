# reports/

Кожен файл тут — окремий звіт. Головна сторінка (`../index.html`)
автоматично читає цю папку при завантаженні — нічого більше редагувати
не треба.

## Додати новий звіт

1. Скопіюй `_template.html` → `03-назва-теми.html` (номер спереду —
   для порядку в списку, з нулем: 01, 02 ... 10).
2. Заповни позначені `ЗАПОВНІТЬ` місця своїм текстом, кодом, фото.
3. Онови `<meta name="report-title">` і `<meta name="report-subtitle">`
   у `<head>` — саме звідси головна сторінка бере назву в списку.
4. Заливай фото у `photos/<назва-звіту>/...` і посилайся на них як
   `../photos/<назва-звіту>/файл.png` (на рівень вище, бо звіт лежить
   у reports/).
5. Заливай готовий `.html` файл сюди через GitHub → Add file → Upload
   files. Онов сторінку — звіт з'явиться в списку сам.

`_template.html` і цей README у список не потрапляють — вони
приховані навмисно (див. `IGNORED_FILES` у `script.js`).
